Forecasts Grand Theft Auto VI's launch-day Twitch viewers hour by hour. Per-hour ridge regression on log viewer ratios across 38 past game launches, using hour-1 viewers, channels, and the pre-release trend — with shrinkage toward the house baseline for launches bigger than any comparable. Leave-one-out loss 0.481 vs the house baseline's 0.930 on the same 37 launches.
